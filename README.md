# WIND MOON 통합 업무공간

대문: https://heysyu84.github.io/windmoon/

| 경로 | 도구 |
| --- | --- |
| `/staff/` | 직원관리 로그인·근무·급여 |
| `/operations/` | 운영관리·일마감·지출 |
| `/menu/` | 메뉴판 편집 |
| `/cards/` | 명함 편집 |
| `/recipes/` | 바 레시피 |

공개 저장소에는 대문, 접속 경로, 직원관리의 정적 화면과 로고·글꼴만 둡니다. 업무 원본과 비밀 값은 포함하지 않습니다. 업무 자료와 인증은 기존 서버에서 관리합니다.
원본 소스는 비공개 `heysyu84/windmoon-source`의 `staff/`, `operations/`, `portal/` 하위 폴더에서 관리합니다. GitHub Pages는 main 브랜치의 루트에서 게시합니다.
기존 `windmoon-admin` 주소는 직원관리 새 경로로 안내하는 호환 주소입니다.

비공개 도구는 대문의 일반 링크에서 각 사이트의 `/signin-with-chatgpt?return_to=%2F`로 최상위 창 이동합니다. 중간 페이지의 자동 새로고침으로 인증을 시작하지 않습니다. 하위 진입 폴더를 직접 연 경우 로그인 버튼을 누르면 기존 권한으로 해당 도구에 접속합니다. 직원관리는 기존 자체 관리자 로그인을 사용합니다.
