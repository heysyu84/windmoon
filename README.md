각 프로그램은 GitHub의 해당 폴더에서 직접 실행합니다. 메뉴판·명함·레시피는 ChatGPT 로그인을 거치지 않습니다. 직원관리와 운영관리는 기존 관리자 계정을 공유하며, 로그인 유효기간 안에는 프로그램을 이동할 때 다시 로그인하지 않습니다.

이 저장소에는 공개 실행 화면과 로고·글꼴·예시만 포함합니다. 실제 직원·급여·장부 자료와 서버 비밀 값은 기존 서버에 보관합니다. 비공개 서버 원본은 heysyu84/windmoon-source에서 관리합니다. 메뉴판의 기본 세트 그림은 기존 공개 GitHub pungwol-menu의 자산을 재사용하며, 개인 웹 저장 문서와 업로드 사진은 포함하지 않습니다.
