# WIND MOON 통합 업무공간

대문: https://windmoon.pages.dev/
보조 접속: https://heysyu84.github.io/windmoon/

| 경로 | 프로그램 | 저장 |
| --- | --- | --- |
| staff/ | 직원·근무·급여와 매출·지출·운영보고서 | Cloudflare Workers·D1, 관리자 로그인 |
| attendance/ | 출근 현황 조회 | 로그인 없이 공개된 출근 정보 조회 |
| operations/ | 기존 운영관리 주소에서 워크스페이스로 연결 | 직원관리 로그인 공유 |
| menu/ | A3 메뉴판 편집 | 이 브라우저, JSON 백업 |
| cards/ | 명함 편집·PDF 출력 | 이 브라우저, JSON 백업 |
| recipes/ | 바 레시피 | 로그인 없이 조회, 즐겨찾기는 이 브라우저 |

메뉴·대문 카드·최근 사용은 현재 접속 도메인의 해당 폴더에서 직접 실행합니다. Cloudflare에서 GitHub로 강제 이동하지 않습니다. 메뉴판·명함·레시피는 ChatGPT 로그인을 거치지 않습니다. 직원관리와 운영관리는 기존 관리자 계정을 공유하며, 로그인 유효기간 안에는 프로그램을 이동할 때 다시 로그인하지 않습니다.

이 저장소에는 공개 실행 화면과 로고·글꼴·예시만 포함합니다. 실제 직원·급여·장부 자료와 서버 비밀 값은 기존 서버에 보관합니다. 비공개 서버 원본은 heysyu84/windmoon-source에서 관리합니다. 메뉴판의 기본 세트 그림은 기존 공개 GitHub pungwol-menu의 자산을 재사용하며, 개인 웹 저장 문서와 업로드 사진은 포함하지 않습니다.

`main`은 Cloudflare Pages와 GitHub Pages의 공통 배포 브랜치입니다. `staff/`는 비공개 원본의 `scripts/build-public.mjs`로 생성합니다. 직원관리의 HTML과 해시가 붙은 자산은 함께 교체합니다. `operations/`에는 기존 링크를 유지하는 이동 페이지만 게시합니다.


## 2026-10-21 공통 화면
- suite.css / suite-nav.js가 홈·메뉴판·명함·레시피의 탐색과 기본 화면을 통일합니다.
- 각 도구 상단 홈 버튼, 모바일 하단 탐색, 대문 검색·최근 도구를 제공합니다.
- 편집 자료와 메뉴·명함 인쇄 영역은 기존 도구가 관리합니다.
